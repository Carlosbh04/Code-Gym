# Changelog

## 0.1.0 — MVP

- Sesiones de práctica de JavaScript con los cuatro tipos de ejercicio.
- Validación de código aislada en Web Worker, persistencia local y recuperación
  de sesión activa.
- Navegación accesible, responsive y compatible con reduced motion.
- Carga diferida de rutas, CodeMirror y contenido; análisis de bundle y
  auditoría Lighthouse documentados.
- Cobertura Vitest y Playwright en Chromium, Firefox y WebKit.
- Configuración SPA para despliegue en Vercel.
